The method

From shared grasps to a pose gradient.

A grasp must be feasible at both ends of a transfer. Composing single-pose energies gives a differentiable score for this connection.

One chain, different grasps

Let 𝒯 = (T0, …, TN+1) contain fixed initial and goal poses and N intermediate placements. Adjacent transfers can use different shared grasps.

The finite pool 𝒢m contains m grasp candidates. The EBM energy Eφf(T, g) evaluates the compatibility of one grasp with one object pose.

Analytical connectivity

𝒢share(𝐓a,𝐓b)=𝒢f(𝐓a)∩𝒢f(𝐓b)
Cmin=min0≤i≤N|𝒢share(𝐓i,𝐓i+1)|>0

𝒢f(T) contains grasps that pass IK and collision checks at pose T. A positive bottleneck connects every adjacent pair. Motion planning then checks the complete robot transfers.

Differentiable pair score

Eab(g)=Eφf(𝐓a,g)+Eφf(𝐓b,g)
Qpair(𝐓a,𝐓b)=−αlog[1m∑g∈𝒢mexp(−Eab(g)α)]

Compose the energy of the same grasp at both poses, then aggregate over the finite pool. Lower Qpair favors greater predicted compatibility. The parameter α controls score smoothness.

Optimize within a stable placement

𝐓i=Δ𝐓(ξi)𝐓s(mi)
ξi=[xi,yi,θi]T

Each candidate keeps its initialized stable placement mode mi. Position and yaw move continuously through ξi, while the initial and goal poses stay fixed.

Ordinary and balanced objectives

Jseq(𝒯)=∑i=0NQi
RN(𝒯)=1N∑i=0N−1(Qi−Qi+1)2
Jseqλ=Jseq+λregRN

Here Qi = Qpair(Ti, Ti+1). The optional penalty balances adjacent predicted connections. It applies for N ≥ 1, with R0 = 0.

Generate, rank, verify

The ordinary/balanced crossed comparison supports generation with Jseqλ followed by ranking with Jseq in pooled candidate validity. Analytical verification determines acceptance. Search starts at N = 1 and increases the horizon after failure, up to the prescribed budget.

The truncated control

Jseqh sums pair scores over grasps whose composed energy passes h. An empty active set has zero score and zero pose gradient. This gate defines the control objective.

𝒜h={g∈𝒢m:Eab(g)<h}
Qpairh=−αlog∑g∈𝒜hexp(−Eab(g)α)

Arrows encode planar position and yaw. Columns are stable modes. Blue/red reference marks indicate analytically feasible/infeasible poses. Each generating objective uses its own color scale.

Executable trajectories

Cold and Warm, across every object.

Cold starts search without a supplied path. Warm starts use a common executable initialization. All saved examples below use Jseq connectivity guidance.

Connectivity plus a motion objective

B=LTCP+50Pcoll+Plim
ℱ=B+βJ
J∈{0,Jseq,Jseqλ}

LTCP is TCP travel. The collision and joint-limit penalties form the baseline, and β is calibrated independently per object. The full study compares Baseline, Rand, ordinary and balanced guidance.

Read the selected verified output

ΔL(k)=L(k)−L(0)

L(k) is the shortest currently verified TCP length at checkpoint k. Warm uses the common initial length L(0), so negative ΔL means shortening.

Continuous updates, replanning, grasp-pair changes and candidate selection all contribute to the search. Complete-motion checks verify the output.

What the curves measure

Cold has no initial path length. Overlap means the selected verified lengths coincide at those checkpoints. The paper reports success and paired path-length comparisons over ten valid pose pairs per object, with the Warm denominator set by available common initializations.
